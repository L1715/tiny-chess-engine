A chess engine in under 4 KB of Python: 0x88 board, iterative-deepening alpha-beta with a transposition table, killer moves, quiescence over captures, promotions and check replies, and material plus piece-square evaluation. Fixed node budget per move, fully deterministic. Built for the tiny-chess-01 bounty.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
